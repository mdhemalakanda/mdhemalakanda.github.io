    Getting Started

    Quick start: your first test label

    Install the plugin, connect sandbox keys, add the FedEx shipping method to a zone, and create your first test label.

    Prefer to watch first? The video runs the whole quick start end to end; the written steps below are the same path at your own pace. This page is the shortest path from zero to seeing the plugin work. Everything stays in FedEx’s sandbox (the test environment): no real packages move and FedEx does not charge you. Allow about 15 minutes once you have your FedEx API keys.
    Sandbox labels are tests. They never move a real package, and nothing on this page creates real charges. You switch to production only when you deliberately go live — see Going live.
    1

    Install and activate the plugin

    Install the plugin — search for Teamzlab Fedex — on the WordPress Plugins screen and click Activate. The full walkthrough, including manual ZIP upload, is on Installation.After activation, a new FedEx Shipping menu appears in your WordPress admin.
    2

    Get sandbox API keys from FedEx

    The detailed version is on Connecting FedEx credentials. In short:
    1. Sign in at the FedEx Developer Portal with your FedEx account.
    2. Create a new API project and enable at least Rates & Transit Times, Ship, and Address Validation. FedEx updates its portal often — follow the current Create Project flow rather than any exact clicks quoted elsewhere.
    3. Choose the sandbox (test) environment for the project.
    4. Copy the API key (the Client ID) and the Secret key (the Client Secret).
    3

    Enter the keys in the plugin

    1. Go to WordPress Admin → FedEx Shipping → Settings.
    2. On the Authorization tab, enter your keys in Client ID and Client Secret.
    3. Open the Account tab and select Sandbox in Environment (the last field on that tab).
    4. Click Save Changes.
    WordPress reloads and shows a “Settings saved.” confirmation, and a Sandbox badge appears at the top of the Settings page.The Authorization tab, where the Client ID and Client Secret go.
    4

    Add the Fedex Shipping method to a shipping zone

    1. Go to WordPress Admin → WooCommerce → Settings → Shipping.
    2. Open the zone that covers the address you will test with. If you have no zone yet, click Add zone and add one that covers your country.
    3. Click Add shipping method, select Fedex Shipping, click Continue, then Save zone and method.
    The method’s window has only an on/off checkbox and a title — there is nothing FedEx-specific to configure per zone; the services and prices shown at checkout come straight from FedEx.The full walkthrough is on Add FedEx to a shipping zone.
    5

    Place a test order

    1. On your store, add any product to the cart and go to checkout.
    2. Enter a delivery address inside the shipping zone you used.
    3. Select one of the FedEx services offered and place the order.
    FedEx prices appear under the shipping options within a few seconds. The plugin is in instant mode by default, so the label is created automatically the moment the order is placed.
    Checkout prices can be cached for up to 10 minutes. If you just changed your settings and want fresh prices immediately, save the Settings page once — saving forces one fresh quote.
    6

    See the result

    1. Go to WordPress Admin → FedEx Shipping → Shipments & Printings. Your test shipment is listed, with its tracking number.
    2. Open or print the label from the Label column with the View Label button.
    3. About five minutes later, the customer email arrives: “Your Shipment Has Been Created”, with the tracking number and a link to the label.
    The Shipments & Printings list, showing the tracking number and label buttons for your test shipment.

    ​
    It didn’t work?

    Start with Troubleshooting. The most common causes are an empty settings field, a shipping zone that does not cover the test address, or FedEx rejecting the sandbox credentials. The exact FedEx error is written to the WooCommerce logs — the troubleshooting page shows where to look.
