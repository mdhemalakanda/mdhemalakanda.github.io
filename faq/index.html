    FAQ

    Quick answers to the questions store owners ask most about TeamzLab FedEx Shipping.

    Watch the video walkthrough, then follow the written steps below.

    ​
    Setup and accounts

    Do I need a paid FedEx account to test?

    You need a FedEx account to create API projects, but the sandbox is free and generates test labels with no charges. Test labels never move real packages. Wire up the whole store on sandbox first, then switch credentials and Environment to production — see Going live.

    Can I use one API project for everything?

    Yes for rates, labels, and returns. Tracking uses its own configured pair — paste the same keys into the Tracking tab if your project includes the Track API.

    Can I use one FedEx account for two stores?

    Each store keeps its own credentials, account number, and its own daily quota counter, counted from that store’s orders. The plugin does not block you from entering the same FedEx account and keys in two stores — whether FedEx’s own terms allow that is a question for FedEx, so confirm with them before you rely on it.

    Where is my client secret stored — is it safe?

    In the WordPress options table with everything else in the plugin’s settings. It is masked in the UI after save but exists in the page source when Settings renders. Limit Settings access to trusted admins; see Security notes.

    Is it compatible with HPOS?

    Yes. HPOS — WooCommerce’s High-Performance Order Storage, its modern way of saving orders in dedicated database tables — is fully supported. See Compatibility.

    Postal-code validation and service availability return errors — is the plugin broken?

    No: FedEx retired those two sandbox endpoints. The features cannot succeed there; see Troubleshooting.

    Quotas, labels, and orders

    Will labels be bought for every order automatically?

    Only when the customer selects a FedEx rate at checkout and the store is in Instant mode. Orders with other shipping methods are untouched. In Advanced mode a draft is created and nothing is paid until you confirm — see Instant labels and Open Ship.

    Can I stop labels during testing?

    Yes — switch the shipping mode to Advanced (drafts only) on the Shipping tab, or remove the Fedex Shipping method from your shipping zone, or set the plugin’s Environment to a sandbox project. Your developer can also block specific orders with a code filter — see the developer reference.

    Why is there a 10-per-day limit on labels?

    The daily quota defaults to the Free plan tier (10 FedEx checkouts per day). Premium raises it to 100, Golden removes the limit. See quota mechanics. The usage panel on the Settings page is read-only — there is no reset button. The counter resets itself at the start of each day, your store’s local time.

    Do quotes count against my daily quota?

    No. The counter only moves when an order is actually placed with a FedEx shipping method selected — browsing the cart or refreshing checkout doesn’t use your quota. Price quotes are also cached for 10 minutes, so repeat views of the same cart reuse one stored answer.

    Does the customer see delivery dates at checkout?

    Not in the current version — prices only. A developer can expose the transit estimates FedEx returns; see the developer reference.

    Can I rename the FedEx shipping method?

    Yes — the row’s name in your zone’s method list is just its title. Click Edit next to the method in the zone’s method list and change the title field (it ships pre-filled as Standard Shipping). That name is admin-facing only: customers never see it, because every price at checkout is labeled with FedEx’s own service name, for example FedEx Ground®.

    Does Product Box change the prices customers see?

    No. Product Box only decides how items are split into packages on the label after checkout. Checkout prices are always quoted for the whole cart as one package — see Product Box.

    What does the plugin do when FedEx is down?

    Checkout keeps working. The FedEx method quietly returns no rates, and any other shipping methods you offer still show. The plugin retries a failed price request once, then hides FedEx rates rather than showing an out-of-date price — failed answers are never cached. See Troubleshooting.

    The customer closed the return-label tab — can I resend it?

    The return portal does not email labels. You can create a fresh return label from the shipment’s row under FedEx Shipping → Shipments & Printings, or retrieve the original from your FedEx account — see Returns.

    Does deleting a shipment delete the order?

    Deleting a canceled shipment permanently deletes the linked order — by design. Non-canceled shipments refuse deletion. Never “empty trash” with shipments inside unless you mean it. See the warning.

    What happens to my shipment records if I delete the plugin?

    Deleting the plugin removes its settings and all shipment records it created, and cancels its scheduled email task. Your WooCommerce orders are kept, including the FedEx tracking number and label link stored on each order, and label PDFs already saved on your server stay in place. See Uninstall.
