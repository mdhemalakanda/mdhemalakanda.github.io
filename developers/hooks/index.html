    Hooks & filters

    Every filter and action the plugin fires, grouped by purpose, with arguments and expected returns.

    The plugin is filter-driven end to end. Everything below is verified in source — all 76 filters the plugin fires are listed here, plus every action; file references point into includes/. Return values must match the type of the default — filters are applied with (int), (string), (bool) or (float) casts as noted.

    ​
    The ship payload chain — fshipping_ship_payload

    The centerpiece. Applied to the instant-mode ship request (array $payload, WC_Order $order, array $shipping) at HTTP/Shipment.php:808; return the modified payload array.
    PriorityClassAdds
    10Events\SpecialServicesInjectorSpecial service types (e.g. signature options)
    20Events\ETDOrchestratorElectronic trade documents attachment
    25Trade\CommercialInvoiceBuilderCommercial invoice + commodity lines
    30Events\AdvancedServicesInjectorAdvanced services enrichment
    35Events\ProductBoxPayloadInjectorProduct Box multi-package packing
    add_filter( 'fshipping_ship_payload', function ( $payload, $order, $shipping ) {
    $payload['requestedShipment']['declaredValue'] = 500;
    return $payload;
}, 40, 3 );

    WooCommerce core hooks the plugin uses

    Not extension points, but relevant when debugging: woocommerce_shipping_methods (registers fshipping_custom), woocommerce_cart_shipping_packages at priority 99 (tags every package with fshipping_config_ver so a settings save forces one recalculation), update_option_fshipping_options (bumps fshipping_rates_config_version), wc_order_statuses (adds the two advanced-mode statuses), map_meta_cap (shipment deletion guard).
